# android-boot

This repository is a starter template for Android development and coding tests.

## Conventions
All architecture and coding conventions are strictly maintained under `.agents/conventions/`:
- [android.md](.agents/conventions/android.md): Project architecture, tech stack, and coding conventions.

## Skills
Available agent workflows and tool runbooks are located in `.agents/skills/`:
- `analyze-requirements`: Requirement analysis and UI model breakdown.
- `create-network-datasource`: Network DataSource and Repository generation.
